# Business Unified Skill

This skill provides comprehensive guidance for business strategy, communications, and requirements engineering. It is organized into specialized reference modules to keep the context window efficient.

## Usage

Consult the relevant reference module when performing specific tasks:

- **Executive Strategy & Board Simulation**: See [references/chief-officers.md](references/chief-officers.md)
- **PR & Communication Strategy**: See [references/pr-manager.md](references/pr-manager.md)
- **Software Requirements Engineering**: See [references/requirements-engineer.md](references/requirements-engineer.md)

## Workflow

1. Identify the business domain of your current task.
2. Load the corresponding reference file from the `references/` directory.
3. Apply the patterns, rules, and best practices defined in that module.
